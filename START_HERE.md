## 🛠️ ПОЛЕЗНЫЕ КОМАНДЫ

### Просмотр логов

```bash
# Все логи
docker-compose logs -f

# Только backend
docker-compose logs -f backend

# Только frontend
docker-compose logs -f frontend

# Только MongoDB
docker-compose logs -f mongodb
```

### Управление

```bash
# Статус контейнеров
docker-compose ps

# Остановка
docker-compose down

# Полная очистка (удалит данные БД)
docker-compose down -v

# Перезапуск
docker-compose restart

# Пересборка образов
docker-compose up -d --build
```

## 📊 СТРУКТУРА ПРИЛОЖЕНИЯ

### Frontend Pages
- `/` - Главная (популярные фильмы)
- `/catalog` - Каталог со всеми фильмами
- `/movie/:id` - Страница фильма (информация + плеер + комментарии)
- `/login` - Вход
- `/register` - Регистрация
- `/profile` - Мой профиль
- `/favorites` - Избранное
- `/history` - История просмотров
- `/admin` - Админ-панель (для админов)

### Backend API
- `POST /api/auth/register` - Регистрация
- `POST /api/auth/login` - Вход
- `GET /api/auth/me` - Текущий пользователь
- `GET /api/movies` - Все фильмы с фильтрами
- `GET /api/movies/:id` - Информация о фильме
- `GET /api/movies/genre/:genre` - Фильмы по жанру
- `GET /api/user/profile` - Профиль
- `POST /api/user/favorites/:movieId` - Добавить в избранное
- `GET /api/comments/:movieId` - Комментарии
- `POST /api/comments/:movieId` - Создать комментарий
- `GET /api/admin/users` - Все пользователи (админ)
- `GET /api/admin/stats` - Статистика (админ)

## 💡 СОВЕТЫ

1. **Не закрывай терминал с Docker Compose** - там видны логи
2. **Первый запуск медленнее** - скачиваются образы
3. **Кэш браузера** - если видишь старую версию, очистите кэш
4. **Монго сохраняет данные** - они сохраняются между перезапусками
