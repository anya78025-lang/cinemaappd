## 🌐 **API ЭНДПОИНТЫ**

### **Аутентификация**
```
POST   /api/auth/register     - Регистрация
POST   /api/auth/login        - Вход
GET    /api/auth/me           - Текущий юзер
```

### **Фильмы**
```
GET    /api/movies            - Все фильмы с фильтрами
GET    /api/movies/:id        - Информация о фильме
GET    /api/movies/genre/:genre - Фильмы по жанру
POST   /api/movies/sync-tmdb  - Загрузка из TMDb
```

### **Пользователь**
```
GET    /api/user/profile            - Профиль
POST   /api/user/favorites/:id      - В избранное
DELETE /api/user/favorites/:id      - Из избранного
POST   /api/user/watch-history      - История просмотров
GET    /api/user/watch-history      - История
GET    /api/user/recommendations    - Рекомендации
```

### **Комментарии**
```
GET    /api/comments/:movieId       - Комментарии
POST   /api/comments/:movieId       - Создать
PUT    /api/comments/:id            - Редактировать
DELETE /api/comments/:id            - Удалить
POST   /api/comments/:id/like       - Лайк
```

### **Администратор**
```
GET    /api/admin/users       - Все юзеры
DELETE /api/admin/users/:id   - Удалить юзера
GET    /api/admin/stats       - Статистика
POST   /api/admin/movies      - Добавить фильм
PUT    /api/admin/movies/:id  - Редактировать
DELETE /api/admin/movies/:id  - Удалить
GET    /api/admin/comments    - Все комментарии
DELETE /api/admin/comments/:id- Удалить комментарий
```
